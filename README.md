# Stoacı Günlük

Bu depo basit bir web sitesi içerir. Kullanıcılar günlük düşüncelerini kaydedebilir ve tarayıcıda saklayabilirler.

## Kullanım

1. `index.html` dosyasını bir tarayıcıda açın.
2. Metin kutusuna günlüğünüzü yazın ve **Kaydet** düğmesine basın.
3. Kayıtlarınız sayfanın altında listelenecektir ve tarayıcıda saklanacaktır.

Bu proje sadece ön yüz tarafında çalışır, sunucu gerektirmez.
